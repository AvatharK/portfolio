# Nessus Vulnerability Scan Project

## Overview
This project demonstrates vulnerability scanning using Nessus to identify security weaknesses in a system.

---

## Objective
The objective of this project is to scan a target system and detect security vulnerabilities that could be exploited by attackers.

---

## Tools Used
- Nessus
- Linux
- Virtual Lab Environment

---

## Steps Performed

1. Installed Nessus vulnerability scanner.
2. Configured scan settings.
3. Entered the target IP address.
4. Started vulnerability scan.
5. Analyzed the results generated by Nessus.
